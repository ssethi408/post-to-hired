# Your profile

Copy this folder to a `profile/` folder inside the working folder you start Claude in, then fill it in. If you keep it inside a clone of this repo, it is gitignored.

| File | Used by | What goes in it |
|---|---|---|
| `author.md` | linkedin-post, linkedin-funnel-playbook | Who you want engaging, what they get, goals, proof bank, jargon list, last 3 posts |
| `voice.md` | linkedin-post, karpathy-post-review | How you write: tone, banned words, openings, closings, real samples |
| `settings.md` | tailor-resume, pipeline-tracker | Where your master resume lives, where tailored PDFs go, where the tracker lives |
| `targets.md` | tailor-resume, find-hiring-managers, mock-interview | Roles, level, industries, location, comp, dealbreakers |
| `about-me.md` | mock-interview, linkedin-post | Your story bank: situation, what you did, result, lesson |
| `interview-rubric.md` | mock-interview (optional) | Scoring dimensions for your field |

Nothing in `profile/` is ever committed. Keep it that way.
