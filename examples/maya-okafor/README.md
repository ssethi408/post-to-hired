# Example profile: Maya Okafor (fictional)

Maya is not a real person, and every company, number and story here is made up. She's a senior product manager in logistics software looking for a Director of Product role.

Use this to see what a finished `profile/` looks like, or to try the skills before you write your own:

```
cp -r examples/maya-okafor/profile ./profile
```

Then try: "Help me write a LinkedIn post about the carrier onboarding story", or "Run a mock interview for a Director of Product role." Delete it and run the setup skill when you're ready to make your own.
