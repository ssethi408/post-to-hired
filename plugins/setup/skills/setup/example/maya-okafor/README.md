# Example profile: Maya Okafor (fictional)

Maya is not a real person, and every company, number and story here is made up. She's a senior product manager in logistics software looking for a Director of Product role.

Use it to see what a finished `profile/` looks like, or to try the skills before you write your own. The easiest way to load it: start Claude in your working folder and say "set me up with the example profile". The setup skill copies these files into `profile/` and marks them as the example.

Then try: "Help me write a LinkedIn post about the carrier onboarding story", or "Run a mock interview for a Director of Product role." When you're ready, say "set me up" and the setup skill replaces the example with your own profile.
